# 当前官方数据集的最终提交材料

比赛：2026 年第八届全国高校计算机能力挑战赛，人工智能挑战赛，胸部 X 光片多标签疾病分类。官网规则于 2026-10-23 再次核对。训练只使用主办方 train 划分，验证集用于选模型、聚合和阈值；未使用外部数据或预训练权重，未执行网站提交。

## 选定结果

四个训练阶段共 107 轮；独立模型与微调模型的所有等权非空子集、四种检查级聚合、两种翻转设置合计 **120** 个部署配置，均按相同确定性环境比较。先比较验证 Macro-AUC，相等再比较自定义阈值 Macro-F1，之后考虑计算量。

最终为 ResNet18 类别空间注意力 + ASL（第 1 轮最佳）与 EfficientNetV2-B0（第 19 轮最佳）等权集成；均为 384 输入，优先正位聚合，无翻转增强。每个检查先聚合各模型的图像概率，再平均模型概率。

| 官方验证集指标 | 数值 |
|---|---:|
| 检查数 | 859 |
| Macro-AUC | 0.7881391330 |
| Macro-F1，阈值 0.5 | 0.3999299286 |
| Macro-F1，自定义类别阈值 | 0.4554294415 |

F1 阈值在同一验证集上选择，可能偏乐观。测试标签由主办方保密，未声称隐藏测试分数、排名或 SOTA。

## 复现与耗时证据

完整 2,218 张测试原图在私有 SSD 上逐张对照原始 JPG 摘要核验。使用包内代码、冻结报告、仅测试集元数据和原图，不读取验证标签、不使用预处理缓存，独立生成 14,140 行概率；与原文件最大差值 **0.0**。

核验覆盖完整文件摘要、模型与报告绑定、冻结阈值、原始患者/检查 ID、每检查十类、无重复、概率范围，以及概率/Gate 不落在同一格点。验证报告在本地 `outputs/final_selection_v1/verification.json`。

测时环境：Windows、Python 3.12.15、PyTorch 2.10.0 cu126、torchvision 0.25.0 cu126、CUDA 12.6、cuDNN 91002、RTX 4070 SUPER；timm 1.0.30、Pillow 11.3.0。
