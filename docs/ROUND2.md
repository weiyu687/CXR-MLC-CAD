## 已完成的诊断

- train / valid / test 患者、检查、图像 ID 没有交叉；同一检查多图标签一致。
- 验证集只有 228 位患者，患者内重复检查较多。第一轮按患者整簇重采样的 400 次验证 AUC 95% 区间约为 [0.7520, 0.8213]；它不是测试分数区间。
- 同患者概率均值融合的 0.25/0.5/0.75 强度均未超过第一轮基线，未采用。
- 仅用官方 train 学得的视角、体位、图像数量分类器，单独验证 AUC 0.629606；与第一轮及新 ResNet50 混合均未提高相应图像基线，未采用。实际 CSV 无 Support Devices 字段，未假造。
- 对实际 320/384/448 输入检查了缓存与原图 ImageNet 归一化路径，抽样张量相同。完整新模型的全测试独立复现尚未执行，不能将抽样检查冒称最终交付验证。
- 固定 StudyPredictor 在混合正/侧位及无正位回退检查上，与 batch=1 的共享推理路径比较，4 种聚合×2 种 TTA 的概率差为 0；这是功能检查，不是 T4 性能认证。

## 研究后保留的训练入口

`tools/run_imagenet_round2.ps1` 和 `tools/finish_imagenet_round2.ps1` 仅保留为历史流程，不自动续跑。新的小规模对照入口为：

```powershell
python -m tools.run_research_ablation --cache <已生成的448缓存目录>
```

默认仅打印参数，便于检查：同一 ImageNet DenseNet121、模型 seed=2036、患者 split_seed=2030，比较加权 BCE 与仅增加两轮分类头预热。传入 `--execute` 才执行，已有输出目录会拒绝覆盖。ASL 对照可用 `--variants asl_head_warmup` 单独指定；这是损失配方对照，不宣称只改变了一个标量。

所有对照仅用官方 train 中预先划定的 12% 患者选择轮次；官方验证先报告。新增 `--split-seed` 使模型初始化种子与数据划分分开。新建任务默认按硬标签损失加权实现 Mixup；恢复旧 checkpoint 时使用其记录的目标，缺失字段沿用旧 soft-target 语义。当前预定第一组对照不启用 Mixup，先避免交互因素。
