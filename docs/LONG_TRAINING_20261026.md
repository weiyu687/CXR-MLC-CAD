# 显存实测和长训练

日期：2026-10-26。用户指出显存占用较低、近期实验轮数较少，要求继续开发。本轮保留已验证的 [第二轮交付](ROUND2_FINAL_RESULTS.md)，增加两组固定长训练。此文先记录已完成的资源测量和预先确定的配方；训练结果随后补充。

## 为什么既要增加轮数，也要改变配方

此前 EfficientNetV2-S 320 在第 5 轮取得验证 AUC 0.801888；到第 9 轮，训练损失从第 5 轮的 0.508886 降到 0.357792，AUC 却降至 0.789195。448 微调在第 2 轮达到 0.801982，第 5 轮为 0.794681。DenseNet 的独立患者留出也在后期出现下降。这些日志支持“原配方存在过拟合”，不能仅据轮数认定尚未收敛。微调轮数还不等于上游阶段的累计轮数。

检查时原训练队列已结束，约 1.2GB 是桌面等程序的设备占用，不是训练峰值。新增资源测量包含网络、EMA、AMP 反向传播、梯度裁剪和 AdamW 状态，记录 allocated/reserved，而不是仅看模型载入或分类头预热。

## 冻结的有限训练计划

| 参数 | ConvNeXt-Tiny | EfficientNetV2-S |
|---|---|---|
| 初始化 | Torchvision 通用 ImageNet-1K V1 | 此项目 320 阶段第 5 轮 EMA |
| 输入 | 448 | 384 |
| 批量 / 加载进程 | 32 / 4 | 32 / 4 |
| 总轮数 | **36，禁用早停** | **36，禁用早停** |
| 骨干初始学习率 | 5e-5 | 1e-5 |
| 分类头学习率倍数 | 5 | 1 |
| 分类头单独预热 | 2 轮 | 0 |
| AdamW weight decay | 0.05 | 0.01 |
| Mixup alpha | 0.2，半数训练批次，两份硬标签损失加权 | 同左 |
| EMA decay | 0.999 | 0.999 |
| 调度 | 2 轮渐升、36 轮余弦、最低为初始率 5% | 同左 |
| 种子 | 2041 | 2042 |

两组均用全部官方 train、按检查抽样并优先正位、既有温和增强、正类加权 BCE。bias、LayerNorm/BN 一维参数不作权重衰减。每轮评估 official valid，以 Macro-AUC 保存最优 EMA，另外保存最后一轮及优化器状态。即使短期没有改善，也完成全部 36 轮。

由于架构、初始化和正则化也有改变，此计划比较的是完整长训练配方，**不能单独归因“增加轮数导致涨分”**。valid 被反复用于选择，后续所有成绩仍需说明选择偏差。

公开入口 `python -m tools.run_long_training` 默认只打印命令；加 `--execute` 才执行固定队列。队列在执行前保存 `plan.json`，含训练命令、代码 SHA256、Git 提交、初始权重摘要、资源测量和既有 CSV 摘要。两组串行训练，避免相互争夺 GPU。现有训练与提交目录不会被复用或覆盖。

训练结束后，以原交付三个成员加两个新成员为候选，仅在 valid 比较最多三模型组合及预定融合，原 0.8111219097 的固定逐类方案也作为明确候选保留。继续使用统一 PyTorch 2.10、batch=1 导出、valid 原图低负载耗时筛查。方案冻结后才进行 test 原图复现。不向比赛网站提交。

## ConvNeXt 来源与许可记录

采用 CVPR 2022 的 ConvNeXt V1 架构、Torchvision 的公开非医学 ImageNet-1K 权重；不是 ConvNeXt V2 的 NC 权重，也不使用任何医学预训练。官方 [模型文档](https://docs.pytorch.org/vision/0.23/models/generated/torchvision.models.convnext_tiny.html)、[带权重 URL 的实现](https://raw.githubusercontent.com/pytorch/vision/v0.23.0/torchvision/models/convnext.py)、[Torchvision BSD-3 许可](https://raw.githubusercontent.com/pytorch/vision/v0.23.0/LICENSE)及 [论文](https://arxiv.org/abs/2201.03545)已核对。权重 SHA256 为 `983f1562536e84ff750a1576fb08e54de751dbf2e17c0d8a4a13704341fdcd3d`，CPU 实际载入和十标签前向检查通过。来源写入 `docs/pretraining/imagenet_sources.json`，文件仅保存在本地审计缓存。
