## 新增实现

- `tools/compare_patient_holdout.py`：重新导出 train 患者留出预测，检查患者列表与 checkpoint 的划分参数相符、不同模型检查/标签/患者顺序一致。拒绝全 train 微调或从比赛 checkpoint 初始化的模型，防止把已见患者当独立留出。不读取 test。
- `tools/patient_statistics.py`：按患者整簇、有放回重采样；所有模型使用相同患者抽样。用患者抽中次数作为其全部检查的权重，计算十类 AUROC、Macro-AUC 与相对参考模型差值的 95% 百分位区间。得分并列按半对计；某轮缺少某类正或负样本时，对全部模型共同剔除此轮，并报告数量。区间仍受 checkpoint/模型选择影响，不宣称是独立确认。
- `tv_densenet121_query`：相同 DenseNet121 骨干接小型疾病查询分类头，256 维、4 头交叉注意力、10 个可学习查询、逐类线性读出；显式 `batch_first=True`。它参考 Query2Label 的一般思想，未宣称完整复现 Query2Label、ML-Decoder 或论文成绩。当前未训练、未加入部署候选，先保留 GAP 分类头完成损失/预热对照。
- `predict.py --validation-only`：仅访问 valid CSV/图像、导出验证指标和可选逐图概率，不生成提交 CSV、不要求 test 存在。`tools/finalize.py` 已改为调用此入口导出候选，方案选定后才执行最终测试推理；真实新包尚未生成。
- `StudyPredictor` 在同一次检查调用内共享原图读取、448 灰度/JPEG 规范化解码，以及相同输入大小/归一化的张量。每次调用仍重新读取文件，不跨检查或跨调用缓存。这样减少集成中的重复解码；实际延迟仍以最终测时为准。
- `src/ensemble.py` 统一固定全局融合权重。除等权外，两模型比较 1:3、3:1，三模型比较 2:1:1 的三个排列。每一组权重同时用于十个类别，不逐类拟合。保存于冻结报告并绑定模型顺序，`predict.py`、`StudyPredictor`、`cost.py` 与选择/打包/核验工具共享相同定义；零、负数、非有限数与数量不符的权重会拒绝。

查询模块不使用独立位置编码：它对 CNN 特征的空间排列不敏感，空间信息来自骨干。分类头内部无跨图像注意力；骨干正常微调时的 BatchNorm 按常规更新，推理时固定为 eval。

## 已通过的检查

在训练环境 PyTorch 2.8 与目标版本 PyTorch 2.10 中均通过：

- 带大量并列分数、患者检查数不等时，加权 AUROC 与 sklearn 的 `sample_weight` 结果误差小于 1e-14。
- 相同模型的患者配对差值区间严格为 [0, 0]；固定种子完全复现；原始划分缺失的类别采用固定排除策略。
- 查询头的 batch/单图结果一致；替换其他图像不改变当前图像结果；空间 token 重排、梯度、严格权重加载、分类头预热期间的骨干参数与 BN 冻结检查通过。这些检查使用合成张量，不是临床数据或泛化成绩。

第二组真实训练完成两轮分类头预热后，另在 PyTorch 2.10 核对该 EMA 与已审计的 ImageNet 初始化：骨干及 BN 的 **725 个状态张量全部逐元素相同**，随后训练进入 full_finetune。该检查验证冻结实现，未将预热阶段的低 AUC 当作最终模型优劣结论；完整对照仍在运行。

另在 PyTorch 2.10 通过完整合成部署检查：只有 valid、没有 test 时候选导出可运行，验证概率与完整导出严格相同；同时覆盖旧/新阈值规则、缓存与原图打包复现、模型摘要绑定和仅 test 数据复现。

共享解码在 PyTorch 2.8/2.10 的合成 JPEG 检查中，与成员分别读取预处理的结果严格一致，覆盖 4 种聚合、TTA 开关、混合输入大小/归一化、无正位回退、重复调用及计时图像摘要校验。三个模型对同一检查的每张有效图像只做一次规范化解码，重复调用会再次解码。它不改变预测定义，也不是已实测的新提交包加速结论。

固定权重网格检查使用构造的排序例子，验证非等权能够被选择器检出，未把合成例子的 AUC 当真实模型成绩。PyTorch 2.10 的整包检查另外覆盖两个不同权重模型的 1:3 混合，冻结校准后仅凭 test 数据独立从原图复现，CSV 概率差为 0。原有无权重字段的等权逻辑保留原始求均值算法。

## 同骨干权重平均实验

参考 [Model Soups，ICML 2022](https://proceedings.mlr.press/v162/wortsman22a.html) 的权重平均思想，另构造同一 DenseNet121 第 5/6 轮 EMA 的 1:3、1:1、3:1 参数平均，并与两个源模型在相同 PyTorch 2.10 验证路径重新比较。该论文的主要实验证据不来自本胸片比赛，不能先验断言有效；当前是小规模检查点平均实验，不宣称完整复现论文。

`tools/build_weight_soups.py` 不读取图像，不继承父模型指标或训练轮次作为新模型的成绩。浮点参数和浮点缓冲取相同比例的平均，整数 BN 计数取最大值；不重新估计 BN。工具检查架构、输入、状态键/形状/类型与同源通用预训练摘要一致，记录源权重摘要、脚本摘要与工作树状态。输出为一个普通骨干模型，推理模型数量不因此增加；是否保留由重新计算的验证指标决定。

`tools/check_weight_soups.py` 以合成状态验证平均计算、整数处理、不修改父模型、不复制指标，以及不兼容/非有限权重拒绝。五个真实候选均在 Python 3.12 / PyTorch 2.10、CUDA、batch=1、无 TTA、优先正位的同一部署路径重新计算，结果如下。未读取测试图像。

| 参数权重（第5轮 : 第6轮） | 官方验证 Macro-AUC | 调阈值 Macro-F1 |
|---|---:|---:|
| 1 : 0（单源） | 0.796978 | 0.468926 |
| 0 : 1（单源） | 0.792493 | 0.463338 |
| 1 : 3 | 0.795397 | 0.467873 |
| 1 : 1 | 0.796854 | 0.467518 |
| **3 : 1** | **0.797574** | **0.471519** |

3:1 的 AUC 点差为 +0.000596；228 位患者整簇配对 bootstrap 1000 次、seed=2042 的差值 95% 百分位区间为 **[-0.001090, 0.002530]**，跨过零。此前训练记录的源模型指标来自 2.8，本表统一以 2.10 重算。五候选的四种聚合比较中，仍是 3:1 参数平均、frontal 最佳。

该候选已通过 `--extra-runs outputs/soup_baseline_s2036_v2/mix_3` 显式加入后续最终验证比较，未据此提前生成提交 CSV。原始逐图预测、完整区间与来源摘要在本地 `outputs/soup_baseline_s2036_v2/validation_comparison.json`；不公开逐例结果。后续更强模型仍须按同一部署路径比较，不把这个微小增益解释成已确认的榜单提升。

| 同条件配置（frontal、无 TTA、batch=1） | Macro-AUC | 调阈值 Macro-F1 |
|---|---:|---:|
| 原交付两模型，使用完全相同的已交付权重重算 | 0.788140 | 0.455429 |
| 旧 EfficientNetV2-B0 单模型 | 0.781899 | 0.445212 |
| 旧 ResNet18 类别空间注意力 ASL 单模型 | 0.780128 | 0.454160 |

## 患者分组验证的逐类固定融合

对上节相同的三个模型，增加逐类权重，同时将其收缩到全局权重以限制自由度。每个拟合折先从等权与三种 2:1:1 全局比例中选择，再对每类从 1/4 步长的三模型单纯形网格和等权中选择；AUC 平分时取最靠近全局权重者。收缩强度仅比较 0、0.25、0.5、0.75、1，按 2045—2049 五个固定种子的五折患者分组 OOF AUC 均值选择。

| 逐类权重强度 | 五次 OOF Macro-AUC 均值 |
|---:|---:|
| 0（只有全局融合） | 0.798683 |
| 0.25 | 0.800793 |
| **0.5（选中）** | **0.801142** |
| 0.75 | 0.800364 |
| 1 | 0.798349 |

0.5 强度在五次划分中的四次优于同折的全局融合。五次重复使用相同的 228 位患者，并非五个独立样本；此前 CNN 检查点也已按官方验证选择，因此此 OOF 不构成完全独立的模型验证。单个种子 2045 实际偏好强度 0，完整结果保留，未删去不利划分。

按选中强度在完整 valid 重拟合后，通过真实三模型推理重新计算得到 **Macro-AUC 0.806420、调阈值 Macro-F1 0.477395**；与逐个模型导出再融合的结果完全一致。完整 valid 重拟合成绩是偏乐观的模型选择估计，不应与 OOF 混用。强度 1 的重拟合 AUC 虽为 0.809310，但 OOF 较差，未采用。没有读取测试图像或用测试统计量拟合权重。

固定的 3×10 权重、类别顺序和模型 SHA 写入明确的 JSON，并嵌入冻结推理报告。`tools/ensemble_presets.py` 在最终流程中核对源模型、验证 CSV、权重文件摘要及每个新导出的运行配置，重新计算实际 AUC，拒绝缺失成员或与先前证据不符的结果。既有四个单模型候选和这个固定融合均由同一清单显式配置；最终选择前冻结清单字节。

拟合本身可由公开的 `tools/fit_classwise_fusion.py` 复现。该脚本只读取 `valid.csv` 和指定成员的验证导出，严格核对图像顺序、模型/CSV 摘要、batch、TTA 与运行环境；按患者划分拟合权重，保存全部 25 折结果及本地 OOF 数组。AUC 先严格排序，只在完全平分时按全局距离、网格顺序打破平分。已从公开脚本重新运行，五个种子各强度的 AUC、最终权重、患者对齐及第一个重复的实际输出概率均与探索记录完全一致。原始逐例数组不上传仓库。
